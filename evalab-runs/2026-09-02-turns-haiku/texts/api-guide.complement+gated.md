All requests require an API key, which works like a password that identifies you to the API. Generate a key from your account dashboard under API settings. Each request sends this key in the Authorization header at the top of your message, formatted as `Bearer your-api-key-here`. Think of the Authorization header as a container where you tell the API who you are. Treat your key like a password—don't share it or paste it into public sites. If someone gets your key, generate a new one right away and delete the old one. When you send a request without a key or with an incorrect key, the API responds with a 401 Unauthorized error, meaning it rejected your credentials.

The API enforces rate limits to prevent abuse. Each API key can make up to 1,000 requests per hour. When you hit this limit, the API returns a 429 Too Many Requests response. Wait a few minutes before sending more requests, or contact support if you need a higher limit for your application.

All requests to the calendar booking API require authentication. Your API key is a secret code that proves you're allowed to use the service. Get your key from your account dashboard. When you make a request, include this key in the Authorization header using the format "Bearer [your-key]". This tells the API who you are and validates your request. Keep your key private and never share it or put it in public repositories. If someone gets your key, they can access your entire account, so treat it with the same care as a password. Revoke old keys from your dashboard if you suspect they've been compromised.

The API enforces rate limits to prevent abuse and ensure fair access for all users. You can make up to 1,000 requests per hour per API key. If you exceed this limit, the API will reject requests with a 429 status code and return a Retry-After header telling you how long to wait. Plan your application to batch requests and cache responses when possible. If your use case requires higher limits, contact support to discuss your needs.

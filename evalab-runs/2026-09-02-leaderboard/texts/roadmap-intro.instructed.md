# Roadmap

This page lists what we're building over the next three quarters, in the order we expect to ship it. It replaces the changelog-only view we've been publishing since 2023, which told you what already happened and nothing about what was coming.

Three things drive what lands here. Support tickets and forum threads set most of the near-term work — the CLI cold-start time and the broken monorepo detection both came from there. Longer items come from problems we hit in our own builds. A smaller set comes from platform changes we don't control, like runtime deprecations we have to track whether we want to or not.

Dates are estimates. Items in the current quarter are scoped and staffed, so treat those as commitments. Items further out are directional; some will be cut. We'd rather show you a plan that changes than an empty page.

What isn't here: anything under active security review, and work tied to customer contracts we can't discuss. Those exist, and they consume engineering time that would otherwise appear on this list.

Each item links to its tracking issue. Comment there if the priority looks wrong to you — that thread is where we argue about ordering, and it does change our minds.

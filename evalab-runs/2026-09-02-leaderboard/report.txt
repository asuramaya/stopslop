HOW TO READ THIS
------------------------------------------------------------------
  These averages cover only the prompts the gate actually acted
  on. Including the rest does not just dilute an effect, it can
  invent one: this report's own earlier shape averaged in prompts
  the loop never touched and showed an 11% drop in sentence-length
  variance that disappeared once they were excluded.

  Compare every gate delta against the noise floor printed under
  it. The control arm is a second ungated generation from the same
  prompt, so its delta is what this model varies by for no reason
  at all. A gate delta smaller than that is not a finding.

  Compare the gate against REWRITE ALONE too. That arm spent the
  same generations on the same prompt and was told only to
  rewrite, never what was wrong. Whatever it gains is what a
  second pass gains. Only the distance between the gated arm and
  that one belongs to the flags.

  Compare the gate against TOLD THE RULES hardest of all. That
  arm spent ONE generation with the enforced checks' own wording
  pasted into the prompt, the way a line in CLAUDE.md would
  arrive. It costs no hook, no install and no extra generation.
  Whatever it reaches is what this project competes against --
  not zero. A gate that only matches it buys nothing.

  Enforced flags falling proves nothing on its own. The gated arm
  rewrote until they fell, so that number only confirms the loop
  ran.

  The held-out number is the finding. It falls with the enforced
  one if the gate taught something general. It stays flat while
  enforced flags collapse if the gate taught avoidance of the
  specific patterns and nothing else.

  Sentence-length stdev falling is the monotone warning: the model
  bought a clean score by flattening every sentence to one shape.
  No check rewards that number, so nothing can be tuned to it.

  30 prompts and one model settle nothing by themselves.
  Read the saved texts side by side before believing any of it.

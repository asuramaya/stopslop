# What we're building next

This is the roadmap we work from. It's the same list our engineers see in planning, published as-is, with dates where we have them and blanks where we don't.

We ship four things this year. Remote debugging for the CLI, so you can attach to a running container without a local rebuild. A rewritten dependency resolver, because the current one takes 40 seconds on a 900-package project and that number has been going up. First-class Windows support, which we have promised since 2023 and have not delivered. And a stable plugin API, frozen for two years once it lands.

Each item below has an owner, a status, and a link to the tracking issue. Status means what it says: "in progress" means someone is writing code this week, "planned" means we have agreed to do it and nobody has started, "exploring" means we are still deciding whether it makes sense.

We move things. When a date slips we edit the entry and note why, rather than quietly deleting it. If something here matters to you and you disagree with where it sits, the tracking issue is the place to say so, and we read every one.

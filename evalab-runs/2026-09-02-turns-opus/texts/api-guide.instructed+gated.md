Each token gets 60 requests a minute, plus a separate limit of 10 bookings a minute on any single calendar. Go over either and the API returns status 429 with a `Retry-After` header telling you how many seconds to wait. This bites hardest when you import an existing schedule, since a loop that creates 500 bookings as fast as it can will be throttled partway through. Add a pause between calls, or send them in batches of 10 with a one second gap.

A note on rate limits before you start building: the caps are low enough that a first attempt can hit them by accident. A loop that fetches one calendar at a time will pass 120 requests in under a minute on a user token, and once you cross the line the API returns 429 and refuses everything until the minute rolls over. Read `X-RateLimit-Remaining` on each response and pause when it gets close to zero. If you do get a 429, the `Retry-After` header tells you how many seconds to wait; wait that long rather than retrying at once, since a retry storm keeps you locked out longer than the original limit would have.

# Roadmap

This page lists what we're building over the next three quarters, in the order we expect to ship it.

We publish it because our users make scheduling decisions based on ours. If you're deciding whether to write a custom adapter for a database we haven't supported yet, you should be able to see that native support lands in Q3 and skip the work.

Three things to know before you read it.

Dates slip. Items in the "Now" column have engineers assigned and are usually within a few weeks of accurate. Items in "Later" are directional, and about a third of them get cut or replaced each year based on what we learn from the ones ahead of them.

Nothing here is a contract. If a roadmap item is load-bearing for your own launch, tell us in the linked issue and we'll tell you honestly how firm the date is.

The roadmap is incomplete on purpose. Bug fixes, performance work, and security patches don't appear here; they ship continuously and account for roughly half of what we do. This page covers changes to the product surface: new APIs, new integrations, and deprecations.

Each item links to a GitHub issue. That issue, not this page, is where the current status lives.

# Day One

Your laptop's on the desk. The badge works — try it on the fourth-floor door now, not when you're in a hurry.

Today has two jobs. Get your environment running, and meet the handful of people you'll talk to most. That's it.

Start with the repo. Clone it, then run `./scripts/bootstrap`. It takes about twenty minutes and it will fail at least once — usually because Docker isn't running. When it does, ask in #eng-help. Someone answers within a few minutes, and nobody keeps score on the question.

By Friday we'd like you to have shipped something to production. Small is fine. A copy fix, a log line, a renamed variable. The point isn't the change; it's that you've walked the whole path from branch to deploy while someone's sitting next to you.

A few things about how we work. Code review is a conversation. If a comment reads as harsh, assume text ate the tone and ask what they meant. We write design docs before big changes and we keep them under two pages. If you've been stuck for an hour, that's the signal to ask, not to push harder.

Your onboarding buddy is [name]. They've blocked time all week, so spend it. Ask the obvious questions now, while "I'm new" is still the easiest sentence in the building.

Lunch is at noon. Someone will come get you.

Local-first sync writes every change to your device first, then reconciles with the server once you're back online. Draft on a flight, edit in a basement office, take notes in a dead zone. Changes queue locally and merge in order when a network appears.

If two devices edit the same note while both are offline, the app compares changes on reconnect. Edits to different paragraphs merge automatically. Edits to the same paragraph keep both versions, shown side by side and marked by device and time, so you choose which one stays.

A dot in the top bar shows synced, syncing, or offline. Tap it for the last sync time or to force a retry.

This ships today on iOS, Android, and desktop. Web sync is planned for October.

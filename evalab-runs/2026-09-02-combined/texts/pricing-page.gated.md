## Pricing

You pay for each person who opens a pull request. Reviewers, bots, and read-only accounts are free.

### Solo — $0

One developer, unlimited public repos, one private. You get the same review model the paid tiers get; we don't withhold the good analysis to sell you an upgrade. The cap is 200 files reviewed per day. No free user has hit it yet, and if you do, we'd like to hear what you're building.

### Team — $19 per developer, per month

Private repos, no limit.

Write your own review rules in plain English — "flag raw SQL outside `db/`" — and scope them per directory. Findings post as one review, not forty separate notifications at 4 a.m. Ships with a GitHub Action, a GitLab template, and a CLI, so the checks that run in CI are the checks you can run before you push. A failed review blocks merge only if you tell it to.

### Self-hosted — talk to us

Runs in your infrastructure. Your model weights or ours, and no source code crosses the network boundary. SAML, audit logs, and a support engineer you can reach by name. Priced in seat bands; the smallest we've sold is 40 seats.

Annual billing knocks off 15%. Tier changes take effect the moment you make them, prorated. Cancel and we delete your data within 30 days — the export API is documented, so pull it out first.

Two things I did deliberately. The free tier states its real limit instead of hiding it, and every claim carries a number or a mechanism behind it. If any of those specifics don't match the actual product, tell me the true ones and I'll swap them in, since vague substitutes would undo most of the work here.

# First A/B run: 2026-09-01

Six prompts, three arms each, `slopwatch`, generated by `claude -p`
(Claude Code 2.1.257). The raw numbers are in `report.txt`, the full
output of both arms is in `texts/`, and everything below is read off
`result.json`.

Read `texts/` before you believe any of this. The numbers are thin.

## What the run actually found

**The dominant result is a base rate, and it was not the thing the run
set out to measure.** Across 1451 words of ungated output, six documents,
the whole of `slopwatch` fired **seven times**: five enforced flags and
two held-out. Two of the six drafts were clean on the first attempt with
nothing to revise. The control arm, generating the same six prompts
again, scored six and one.

So the honest summary of this run is that the model wrote ordinary
technical documentation and mostly did not do the things `slopwatch`
looks for. A tool built to catch those things found one flag per 207
words here, and one held-out flag per 726.

**The gate does reliably clear what it enforces.** Every one of the six
reached zero enforced flags, in 1.7 generations on average. That number
proves only that the loop terminates. The arm rewrote until the checks
went quiet, which is what it was built to do.

**There is no evidence that anything transferred, and no evidence
against it either.** Held-out flags fell 1.42 to 0.84 per 1000 words, a
41% drop that reads well until you look at the line under it: the control
arm, which is just a second ungated sample, fell further, 1.42 to 0.78.
The gate moved the held-out number less than sampling noise did. In
absolute terms the ungated corpus contained **two** held-out flags and
the gated corpus contained one. Nothing can be concluded from a
difference of one flag.

This is the honest position on the Goodhart question: the run had almost
no power to answer it. Testing whether a gate teaches avoidance rather
than writing needs output that trips the gate often enough to measure,
and this output did not.

**No flattening was detected.** Sentence-length standard deviation moved
7.09 to 7.03 under the gate, against a noise floor of 7.09 to 6.69. The
monotone this metric exists to catch did not appear. Type-token ratio and
length also moved less than the control arm did.

## What this does not show

Six prompts, one model, one day. Every caveat that implies.

**The prompt set is biased toward the writing least likely to be
sloppy.** Each prompt supplies real content: a specific incident, named
settings, a concrete API change. Text with something to say is text that
does not need filler. Prompts inviting padding -- launch copy, a post
arguing a position, anything asking to "explain why X matters" -- would
plausibly trip these checks far more, and are the case where the gate
might earn its keep. That run has not been done.

**A low base rate on this model says nothing about a weaker one.** These
checks were ported from linters built against real output that needed
them.

**None of this measures whether the prose is good.** Every metric here is
a proxy. `texts/` is the actual evidence, and reading the two arms side
by side is the only assessment of quality this run contains.

## What to run next

The experiment that would settle the Goodhart question needs prompts that
generate flags. Add a second prompt set built to invite padding, keep the
same held-out split, and re-run. If enforced flags collapse while
held-out flags hold steady across a corpus with real flag density, that
is Goodhart demonstrated rather than suspected. If held-out flags fall
with them, the gate teaches something general, and this project has its
first evidence of that in its whole history.

Until one of those runs exists, the defensible claim about stopslop is
narrow: it removes the constructions it names from text that contains
them, at a cost of roughly 0.7 extra generations per document, on writing
that mostly did not contain them to begin with.

## Reproducing

`recordings/` is absent on purpose. This run was generated before a fix
to the recording key, and its recordings collide: the control arm and the
ungated arm send identical messages, and the old key could not tell two
samples of one prompt apart. The live measurements are unaffected, since
they came from real generations rather than from replay. A fresh
`--live` run records correctly and replays.
